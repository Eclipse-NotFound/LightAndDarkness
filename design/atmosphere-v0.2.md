# 0.2.0 灯光氛围

本版在原有动态照明、命中维修和原版保存上增加氛围层。稳定光、故障光与随身灯共同进入同一张照度图，普通视觉发现继续读取这张图。

## 灯光种类

| 样式 | 默认频率 | 表现 |
|---|---:|---|
| steady | 无闪烁 | 保持亮度；原有暖白、冷白、红色灯色保留 |
| slow | 0.45 Hz | 连续变亮、变暗，约2.2秒一个周期 |
| fast | 2 Hz | 亮、很暗、半亮三段切换，模拟接触不良 |
| burst | 0.8 Hz | 一串短促亮灭后长时间暗下，模拟启动失败 |

原版灯具首次获得可重复的配置：约68%稳定、14%慢闪、10%快闪、8%成串闪断，亮度分为0.35、0.65、1三档。这是按房间与灯具身份生成的分配比例，单间房不保证刚好符合比例。相位也按身份错开，不会全场同时闪烁。

频率指每秒完整周期数；成串闪断的一个周期含多次短亮。闪烁由原版30Hz游戏步推进，暂停时冻结；不会因渲染帧率变化加速。周期时钟不写存档，重新启动相位从会话时间开始；灯具的样式、亮度、频率和维修结果随存档保留。

## 黑暗区

室内自动生成固定位置的柔边暗区；户外不自动生成。默认以560像素网格确定约38%的候选区，暗区尺寸440×440、边缘过渡110像素、中心环境光为原底亮度的8%。黑暗区只压低环境底光，真实灯光仍能照进去，因此随身灯、修灯和打坏灯都有实际作用。重叠区域取更暗者，避免叠乘变成不可控的纯黑。

相机移动不改变区域位置；不会直接修改探索黑幕、Tile.visi或强制抹掉手电。普通视觉感知读取最终照度，听觉、开火暴露和已锁定目标规则沿用原版。

## 玩家设置与维修

“光与暗”页增加五项：故障灯闪烁开关、场景灯亮度倍率（0.25–1.5）、闪烁速度倍率（0.25–2）、局部黑暗区开关、黑暗区浓度（0–1）。这些新增选项随原版存档保存，修改后需要正常保存游戏。单灯基础频率范围0.1–4 Hz，乘全局速度后最高6 Hz。关闭闪烁让现有故障灯稳定输出，不改变故障记录。

受损或故障灯按住Alt+E两秒维修，消耗废金属×2；即使耐久40，故障灯仍可维修。修好恢复40耐久、开启并转为steady，保留该灯原定亮度和色温。完整且稳定的灯按Alt+E开关。断电、手动关闭、耐久归零都优先于氛围效果，避免闪烁让坏灯重新亮起。

## 指定灯具与区域

`../atmosphere.json` 在启动时读取；当前空规则使用上述自动分配。可按土地land、房间room、灯具type或精确key指定灯光。规则按数组顺序取首个匹配，省略条件表示所有；具体规则放在通用规则前。实例：

```json
{
  "version": 1,
  "autoDarkZones": true,
  "lamps": [
    {"land":"rbl", "type":"light1", "mode":"steady", "brightness":0.65},
    {"type":"light4", "mode":"fast", "brightness":1, "frequency":2.5},
    {"type":"light5", "mode":"burst", "brightness":0.35, "frequency":0.6}
  ],
  "darkZones": [
    {"land":"rbl", "room":"loc0_0", "x":500, "y":260,
     "width":400, "height":300, "feather":80, "factor":0.03}
  ]
}
```

坐标、宽高与边缘宽度均为游戏世界像素，factor是区域中心保留的环境光比例。自动和指定区域合计最多128个；要仅使用指定区域，把autoDarkZones设为false。精确灯具key可从开发验证日志的LAMP行获得，格式为类型:坐标X:坐标Y:缩放X:缩放Y:重复序号。

修改灯具规则后重启、进入房间，会按变化后的规则更新已存在的灯具一次。规则不变时保留已维修状态，避免读档后又变成故障灯；删除原规则会恢复该灯的自动配置。明示更新配置可能重新指定故障样式，但不恢复耐久、不改变开关、不扣维修材料。保存格式沿用原version=1的JSON字符串，新增可选字段；0.1存档自动补充氛围字段，旧槽不会被当前状态修改。

## 实现与验证口径

LadAtmosphere负责样式、波形和区域，LadLightField负责最终合成。明暗变化只调整已有光图强度；瞬间输出零时仍保留遮挡缓存。暗区环境底图按视口、底亮度和区域配置缓存，避免固定视角逐帧重画。

独立测试驱动覆盖时间波形、频率、配置更新、柔边、相机移动、光照进入黑暗区、缓存复用和实际维修/保存。算法阶段耗时与整帧FPS、原版大场景预载分别记录；采用KB-000056的测量边界，没有读取其其他模组私有原始报告。

装备/电池、联机同步、DLC和完整生产模组组合仍不在本版认证范围。原版大场景预载停顿仍存在；黑暗区布局是环境氛围分配，尚无关卡设计师逐区域手工调优。
