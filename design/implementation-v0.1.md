# 0.1.0 动态照明与灯具状态

2026-10-15。用户授权实施动态渲染、命中损坏、维修和保存。本版是可运行候选，正式部署另行执行。

## 光照

`LadLightField` 在可视区域生成 12 像素一个采样点的 RGB 照明图，乘到世界显示层中，位于原版 `visLight` 之前。固定灯与移动灯使用同一张图；玩家照度也从这张图采样，避免画面和战斗分别维护两套明暗。

每盏灯以格子射线生成遮挡轮廓，再绘制径向衰减；移动灯支持方向和锥角。瓦片 `opac` 与视口变化会使缓存失效，门开关或墙体破坏不需要全房重画。当前半透明格按沿线累计遮挡处理，尚无透射颜色、软阴影、多次反射或水吸收。

环境底亮度默认 0.14；户外最低 0.6。随身灯默认开启，半径 440，锥角约 104°，另有半径 85 的近身溢光。其朝向来自玩家瞄准点。本轮只提供内置随身灯，装备物品、槽位、电量和掉落链不在已实现范围。

普通视觉的适配点是玩家 `childObjs` 的具名项 `LightAndDarknessTick`：原版玩家 actions 计算完 visibility 后、后续单位 AI 更新前，乘以 `0.18 + 0.82 * 当前照度`。不改 `Tile.visi`、stealthMult、demask、听觉或锁定记忆。已验证原生更新后数值；没有宣称所有特殊敌种均遵循此公式。

## 场景灯

白名单为 light1/2/3/4/5/6/7、stlight1/3/4；排除出口指引光、招牌、彩色布景及 shadow。沿用原版灯壳资源，自行管理开/关/损坏外观。资源实际关灯帧仍可能带白光，因此关闭时另降低灯壳颜色强度。

首次进入场景将这些 BackObj 的 vis/light/erase 引用暂存并移除，消除原版烘焙光，再绘制动态灯壳。灯被打坏或维修只更新自身状态，不重新烘焙房间。

普通房间：保留重绘前图像，原版基准重绘一次、灯光转换重绘一次，以像素差恢复既有绘制痕迹。大场景：利用宿主已有的原生画面历史重放，仅重绘一次；不能复制全部预载块。重绘时暂缓全图预载 3 帧，留出 WallBlend 回收旧覆盖层的时间，再恢复原先开启的预载。仅改运行时公开开关，不写其他模组配置或代码。

代价：转换及总开关的切换仍有秒级停顿；尤其 192×75 场景会重新预载 240 块。当前没有宣称平滑无停顿。普通房间的直接像素改动与大场景 `gwall` 历史标记已验证保留；其他模组绕开原生历史直接改大场景像素，未承诺保留。

## 命中与维修

每盏灯有一个真正继承原版 Unit 的命中代理，只加入 `loc.units`，不加入原版对象更新链。代理无 AI、经验、掉落、SATS 标记和实体碰撞行为；阵营为 0，doop=true。注意玩家阵营是 100，不能用 100，否则玩家子弹会当作友军跳过。

原版 Bullet.run 自行处理轨迹/墙碰撞/命中去重；命中后调用代理的 udarBullet。爆炸也走原版路径。耐久默认 40，破损后禁用代理碰撞并熄灯；修好后重新启用。灯的开关和区域供电分别判断，维修不为断电区域强行供电，也不调用有剧情副作用的 allon/alloff。

在 160 像素范围内有直线可达的最近灯具可交互。完整灯按 Alt+E 开关；受损灯按住两秒维修。以原版 30Hz 游戏步计时，背包至少两份 scrap 才能开始；完成时再次检查并扣除两份，刷新负重。松 E/Alt、失焦、移动超过 12 像素、受伤、菜单/暂停、距离或状态变化中断，不预扣材料。当前没有专用维修工具或技能折扣。

## 保存和退出

`LadStore` 将版本化 JSON **字符串**写进 `Game.triggers["lightanddarkness.state.v1"]`。原版 Game.save 复制触发器值，所以已存槽不会随当前内存对象继续变化。保存灯耐久、开关、随身灯开关；材料仍由原版 Invent 保存。新游戏从默认状态开始，未知格式拒绝覆盖。

房间键包含土地、房间位置/镜像、原始房间 XML 与灯具几何的哈希；灯键使用类型、坐标、缩放、同位置序号。破坏瓦片不会改变键。地图模板/灯几何改变时不会把旧状态强行套到新灯；全部随机生成和重置剧情边界尚未穷尽。

换房、读档会拆除旧代理和更新适配器；关闭模组恢复原版 BackObj 和背景显示，保留存档键以便重开恢复。`fe.*` 编译声明只作为 external SWC，不打入候选；测试探针是另一份 SWF，不进入候选。

## 代码定位

入口 `LightAndDarknessMod`；生命周期/输入/感知 `lad/LadRuntime`；光图 `LadLightField`；原生图像转换 `LadSceneBake`；灯具识别与外观 `LadLampCatalog`；命中桥 `lad/native/LadLampTarget`；保存 `LadStore`；HUD/日志各自独立。生产没有自动开档、传送、加物品、存档槽测试或测试退出逻辑。
