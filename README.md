# LightAndDarkness

为 Remains 增加能影响战斗的明暗区域、可装备灯具，以及场景灯的破坏和维修。用户于 2026-10-15 确认：**战术光暗与生存探索并重，兼顾氛围**。

当前 **0.3.2 已于2026-10-19部署**，新增炮塔与蜘蛛地雷微光，保留弹丸短光、氛围、灯具互动及随身灯平滑，并补充分块绘制后的边框恢复。正式文件固定为 `release/LightAndDarknessMod.swf`，保存进度并重启游戏生效。[本版调查、验证和回退](tests/machine-glow-2026-10-19.md)。

## 当前可用功能

- 八类炮塔沿原版状态灯发出黄/橙/红微光；蜘蛛地雷展开亮黄、追击或跳跃亮红，休眠、收起或损毁时熄灭。灯点跟随转向及墙挂/倒挂姿态，雷霆炮座仅开启能量场时有蓝光；小范围散光受墙门遮挡。
- 「模组 → 光与暗 → 炮塔与蜘蛛地雷微光」默认开启，开关随存档槽保存。

- 场景灯与随身锥形灯实时合成照度，墙体和门遮挡光线。照度层独立于原版探索黑幕。
- 子弹经过时短暂照亮周围：普通弹暖白、燃烧弹橙、等离子绿、电弧青白、冰弹淡蓝、魔法按类型分色；激光照亮真实射线路径，火箭有尾焰光，爆炸有快速衰减的闪光。玩家与敌方共用规则，光会影响普通视觉发现。
- 飞镖、锯片、钉子、毒液和气体不发光；手雷飞行时不亮、引爆时才有爆闪。所有短光尊重墙门遮挡，密集射击会合并邻近光源并限制数量。
- 场景灯有稳定、慢速明灭、快速接触不良、成串闪断四种样式，默认三档亮度，各灯节奏错开。暂停时闪烁停止推进。
- 室内自动出现柔边黑暗区，仍能被真实灯光照亮；可在[氛围配置](atmosphere.json)中指定灯具亮度/频率及区域位置，详见[使用说明](design/atmosphere-v0.2.md)。
- 支持 10 类原版灯具；40 点耐久，原版子弹/爆炸可打坏，灯灭后不再提供照明。
- `Alt+L` 开关随身灯；`Alt+E` 切换最近的完整稳定灯；受损或故障灯按住 `Alt+E` 两秒维修，消耗背包废金属 ×2，修好恢复稳定。松键、走开、受伤或暂停会中断。
- 可在「模组 → 光与暗 → 快捷键」更改上述按键；按键偏好即时保存在本机。
- 灯具耐久、开关与随身灯开关随原版存档保存。关闭模组恢复原版显示，重新开启恢复模组状态。
- 普通视觉发现按玩家所在照度调整；原版听觉、开火暴露、探索格与 SATS 不重新定义。
- ModLoader 的“光与暗”页可调整开关、暗区底亮度、随身灯、视觉发现影响，以及故障闪烁、灯光亮度倍率、闪烁速度、黑暗区开关与浓度。
- 新增「弹丸与爆炸短暂照明」开关与「弹丸照明亮度倍率」（0.25–1.5，默认1），随原版存档槽保存。暂停冻结残光；关闭、换图和读档清理临时光，不把飞行弹或残光写入存档。

随身灯目前是验证玩法的内置灯，还没有新增背包装备、装备槽、电量或灯具道具。原有暗区底亮度/感知开关暂为本次启动偏好；新增氛围选项、单灯样式、随身灯与场景灯状态随存档保存。

## 构建与验证

0.3.2用`build/build-machine-probe.ps1`编译外部探针，再运行`tests/run-machines.ps1 -Mixed -Mode verify`（173项微光）或`-Mode regression`（99项回归）。省略`-Candidate`从正式release读回；传入候选绝对路径可测试build/out中的冻结文件。通过启动器选择隔离组合，使用唯一AIR存储与私有后台桌面。下述旧脚本保留历史用途，当前组合优先走此入口。

在游戏根目录运行 `mods/LightAndDarkness/build/build.ps1 -Tests` 构建候选及独立测试驱动；工具路径可用 `-Java`、`-Tools` 覆盖。依赖只读的本机 Sandevistan 工具链，不复制其源码。

`mods/LightAndDarkness/tests/run.ps1 -SkipBuild -Mixed` 在模组自己的副本中运行，使用唯一 `remains-lad-test-*` AIR 身份。它不使用正式 `pfe` 存储；测试结束只清理自己启动的进程及临时描述符。运行 AIR 需允许创建独立测试存储。`build/build.ps1 -TestsOnly` 可只更新探针、保持已测候选字节不变。

加 `-Installed` 从正式release回读文件及本模组的加载行，并核对测试副本字节；此模式不重编译。组合测试只包含下述已列明的四个接口模组。

弹丸专项用 `build/build-projectile-probe.ps1 -ProbeOnly -Tools <工具目录> -OutputDirectory <候选目录>` 单独编译探针，再运行 `tests/run-projectiles.ps1 -SkipBuild -Mixed -CandidateDirectory <候选目录>`。加 `-Installed` 时只从候选目录读取外部探针，生产模组仍从正式release读回。

0.3.0最终组合已通过 **131项弹丸专项、81项灯具/大场景、21项公共改键、11项跨进程读档及13项平滑边缘检查**；安装后从正式路径再次通过131项。含68种原版弹丸外观枚举、真实武器发射/命中、墙遮光、爆炸、暂停和容量压力，见[本版验证](tests/projectile-verification-2026-10-15.md)。未将68种外观覆盖等同于213款武器逐款实射。

## 项目参数与当前限制

入口为 `LightAndDarknessMod.init(main:*)`，正式路径为 `release/LightAndDarknessMod.swf`，治理沿游戏根 `../../GOVERNANCE.md`。用户授权的 `AGENT_SCOPE.md` 已创建。

当前仅认证本机 1.02 宿主及本轮列明组合；未认证 DLC、联机、全部生产模组同时启用或全部敌种。大场景转换会触发原版预载，实测仍有秒级停顿；逐帧照明耗时与这段预载分开记录。
